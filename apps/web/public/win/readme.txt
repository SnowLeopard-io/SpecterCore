SpecterCore (bk) — virtual disk sample document.

This file ships with the built-in Windows tools and lives on the
virtual disk at Users/Public/Documents/readme.txt. Open it with
Notepad (Windows) from the File > Open dialog once the file dialog
bridge lands, or browse it in File Explorer.

The virtual disk is provisioned at startup from the bundled
resources: Windows/SysWOW64/notepad.exe, its MUI satellites, and a
few real files copied from the host machine (win.ini, hosts).
